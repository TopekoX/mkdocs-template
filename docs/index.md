## What you get

- Light, dark, and system themes (use the toggle in the header).
- Search, breadcrumbs, previous/next navigation.
- Copy buttons on every code block.
- Admonitions, tabs, tables, and diagrams.

    standard normal density is

    $$
    f(x) = \frac{1}{\sqrt{2\pi}}e^{-x^2/2}
